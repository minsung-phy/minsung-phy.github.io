Spec2Maude

WebAssembly SpecTec semantics → executable Maude specifications

Spec2Maude is an automated translation pipeline from WebAssembly SpecTec semantics to Maude rewriting logic. It aims to preserve the source semantics while producing executable formal specifications that support execution, search, and model checking.
