Projects

  • Spec2Maude

    Ongoing

    From SpecTec language specifications to executable Maude semantics

    A general translator from language specifications written in SpecTec to Maude rewriting logic, designed to work for arbitrary SpecTec definitions rather than a single language. As a primary case study, it is applied to the WebAssembly specification: the generated semantics, together with a wasm2maude frontend for Wasm modules and test scripts, supports program execution, state-space exploration, and model checking, and is evaluated against the official WebAssembly core test suite.
